# **App Name**: Air Conditioner Course Hub

## Core Features:

- Video Lessons Display: Displays a list of 10 video lessons with title, description, and embedded video player (iframe).
- Direct Access: Provides direct access to the lessons without requiring login, password, or authentication.
- Mobile-First Optimization: Ensures the page is fully optimized for mobile devices with a responsive layout.
- Lazy Loading: Implements lazy loading for video iframes to improve initial page load time.
- Firebase Hosting Deployment: Designed for easy deployment to Firebase Hosting using a single, optimized index.html file.

## Style Guidelines:

- Primary color: Soft blue (#75A9FF) for a professional and calming feel.
- Background color: Light gray (#F0F2F5) to provide a clean and unobtrusive backdrop.
- Accent color: Darker blue (#3D70A7) to highlight interactive elements and calls to action, creating visual interest without being distracting.
- Body and headline font: 'Inter', a sans-serif, providing excellent readability on mobile devices.
- Single-column layout optimized for vertical scrolling on mobile devices.
- Cards with rounded borders and subtle shadows to organize content and provide a modern look.
- Subtle animations for a smoother user experience.
